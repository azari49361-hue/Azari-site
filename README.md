# AZARI TRADE AI v2

سامانه تحلیل و سیگنال فارکس با تمرکز روی **طلا (XAUUSD)** — تایپ‌اسکریپت + Express + PostgreSQL + React.

> **صداقت در هسته:** این سامانه معامله خودکار نمی‌کند، قیمت/داده/تست جعلی ندارد و ادعای «۲۴ ساعته فعال» بدون heartbeat واقعی نمی‌کند.

## قابلیت‌ها

- **منابع قیمت واقعی** با اولویت: MetaApi (MT5 واقعی) ← Twelve Data ← biquote (رایگان، بدون کلید)
  - اگر هیچ منبعی پاسخ ندهد، وضعیت «اتصال برقرار نیست» نمایش داده می‌شود؛ هرگز قیمت قدیمی به‌صورت زنده نشان داده نمی‌شود.
- **موتور سیگنال فقط روی کندل بسته** — تصمیم هرگز روی کندل باز گرفته نمی‌شود. تایم‌فریم اصلی تصمیم **M5** است (تأییدیه: M15/H1 و روند H4). دلیل M5 نسبت به M1: نویز کمتر، اسپرد سهم کوچک‌تری از حرکت، و نسبت ریسک به ریوارد واقعی‌تر.
- **جلوگیری از سیگنال تکراری**: قید یکتای `(symbol, timeframe, candle_open_time)` در دیتابیس + کول‌داون (۵ دقیقه طلا، ۱۰ دقیقه سایر نمادها — قابل تغییر با `GOLD_COOLDOWN_SECONDS`/`SYMBOL_COOLDOWN_SECONDS`) که برای اسکن دستی هم اجباری است (بدون دکمه force).
- **SL/TP و RR واقعی** از ATR: SL = ۱.۵×ATR، TP1/2/3 = ۱.۵/۳/۴.۵×ATR؛ برچسب RR از فاصله‌های واقعی محاسبه می‌شود.
- **گیت کیفیت M5**: علاوه بر سقف ۰.۵٪ قیمت برای اسپرد، اسپرد باید کمتر از ۲۰٪ ATR کندل پنج‌دقیقه باشد (`MAX_SPREAD_ATR_RATIO`) — وگرنه سیگنال صادر نمی‌شود.
- **فقط طلا سیگنال می‌گیرد**: موتور سیگنال تنها روی XAUUSD اجرا می‌شود؛ XAGUSD/USOIL/DXY فقط قیمت زنده در داشبورد دارند (بدون سیگنال و بدون ارسال به تلگرام).
- **یک مقصد تلگرام**: همه پیام‌ها (سیگنال جدید طلا، پیگیری TP1/TP2/TP3 و SL، هشدار محافظتی) به **کانال** می‌روند؛ مفهوم گروه حذف شده است.
- **وضعیت‌های پیگیری**: ACTIVE → TP1_HIT → TP2_HIT → TP3_HIT | SL_HIT | REVERSED | CLOSED
  - TP3_HIT و SL_HIT نهایی‌اند و هرگز overwrite نمی‌شوند؛ `closed_at` جداگانه ثبت می‌شود.
- **هشدارهای محافظتی**: مرحله ۱ (زرد: فشردگی EMA + مومنتوم مخالف) و مرحله ۲ (قرمز: تقاطع تأییدشده مخالف → REVERSED).
- **پایش کهنگی داده**: اگر کندل بسته‌ی M5 بیشتر از ۱۰ دقیقه کهنه شود (`CANDLE_STALE_ALERT_SECONDS`)، یک هشدار فنی به **چت شخصی خودتان** در تلگرام می‌رود و با تازه شدن داده پیام بازگشت ارسال می‌شود. در همین بازه سیگنال جدید صادر نمی‌شود.
- **وضعیت بازار صادقانه**: شنبه/یکشنبه و جمعه ≥۱۷:۰۰ نیویورک بسته؛ تشخیص فقط با نام روز نیست — تازگی داده قیمت و marketState بروکر هم لحاظ می‌شود.
- **گزارش دوره‌ای بازار (هر ۳ ساعت)**: یک پیام به کانال با دو بخش — ۱۰ نماد طبق فید متاتریدر ۵ بروکر و برابری‌های مرجع بازار جهانی (ECB، روزانه). پیش‌نمایش: `GET /api/report/preview`، ارسال فوری: `POST /api/report/send`. خط تومان **خودکار** از بازار آزاد خوانده می‌شود (priceto.day → nerkhsanj → نوبیتکس/تتر) و `USD_TOMAN_RATE` فقط پشتیبان است. پایینش معادل تومانی **انس جهانی طلا** و **گرم طلای ۱۸ عیار** هم از همان دو عدد واقعی محاسبه و با ذکر فرمول چاپ می‌شود.
- **پنل وضعیت منابع قیمت**: برای هر نماد جداگانه نشان می‌دهد قیمت از کدام منبع آمده (MetaApi/TwelveData/biquote)، اسپرد، سن داده، وضعیت زنده/کهنه/بدون‌داده و وضعیت بازار + آخرین خطاهای پولینگ.
- **کلید منابع داده از داشبورد**: دکمه «منابع داده» در هدر داشبورد؛ کلید TwelveData همان‌جا وارد، قبل از ذخیره با یک درخواست واقعی تأیید و در PostgreSQL ذخیره می‌شود (بدون ویرایش `.env` و بدون ری‌استارت).
- **ساعت شمسی تهران** برای همه ثبت‌ها؛ همگام‌سازی ساعت با شبکه.
- **بدون رمز داخلی**: داشبورد و اسکن دستی بدون ورود کار می‌کنند (خواسته‌ی مالک). هیچ صفحه/پرامپت رمزی وجود ندارد. برای استفاده در اینترنت، دسترسی را در سطح شبکه ببندید: فایروال یا بلوک `allow/deny` در `deploy/nginx/azari-trade.conf` (Basic Auth در nginx هم برداشته شد) — چون تنظیمات تلگرام و اسکن در دسترس هر کسی با لینک خواهد بود. rate limit روی POSTها و redact توکن در لاگ‌ها فعال است.
- **ری‌استارت پیش‌نمایش**: `bash scripts/preview-up.sh` (هاست در `.preview-host` ذخیره می‌شود؛ همان لینک قبلی برمی‌گردد) — همان اسکریپت چک سلامت خودکار را هم روشن می‌کند (`bash scripts/preview-watchdog.sh status`). جزئیات در [`docs/PREVIEW.md`](docs/PREVIEW.md).
- **پایداری**: ذخیره سیگنال در صف (PENDING) داخل دیتابیس با بازیابی پس از ری‌استارت، healthcheck واقعی، Docker با `restart: always`.

## شروع سریع (Docker)

```bash
cp .env.example .env
# مقدار DATABASE_URL را بگذارید (کلیدهای منبع قیمت اختیاری‌اند)
docker compose up -d --build
# داشبورد: http://SERVER_IP:3000
```

جزئیات: [docs/SETUP.md](docs/SETUP.md) و [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)

## توسعه

```bash
npm install
cp .env.example .env   # مقادیر لازم را پر کنید
npm run dev            # سرور + Vite dev (پورت 3000)
npm run typecheck      # تایپ‌چک کلاینت و سرور
npm test               # ۵۹ تست واحد
npm run build          # بیلد production فرانت‌اند
node scripts/smoke.mjs # تست سرتاسری با PostgreSQL واقعی
```

## ساختار

```
server/          سرور Express (tsx runtime — بدون tsc emit)
  config.ts      پیکربندی fail-fast (بدون کلید هاردکد)
  lib/           time (شمسی+همگام‌سازی), marketStatus, indicators, ratelimit, logger
  db/            pool, migrate, repo (همه queryها یکجا)
  sources/       metaapi, twelvedata, biquote — فقط قیمت واقعی، بدون ساخت مقدار
  engine/        quotes, candles, signals (هسته خالص + scanner), dispatcher, tracking, alerts
  telegram/      client (ارسال و اعتبارسنجی) و messages (قالب پیام‌ها)
  routes/        state, live, ohlc, scan, bot, tests, health
migrations/      SQL مایگریشن‌ها (001_init.sql — ۱۰ جدول)
src/             داشبورد React + lightweight-charts
tests/           vitest — موتور، rate limit، redact لاگ
```

## محدودیت‌های صادقانه

- تست‌هایی که به کلید API یا حساب واقعی نیاز دارند (ارسال واقعی تلگرام، MetaApi) با پیام «نیازمند تنظیمات کاربر» گزارش می‌شوند و اجرا نمی‌شوند.
- سیگنال‌ها **تجزیه و تحلیل‌اند، نه توصیه سرمایه‌گذاری**؛ معامله خودکار وجود ندارد.

## نصب روی گوشی (PWA)

اپ «نصب‌شدنی» است: `public/manifest.webmanifest` + `public/sw.js` + آیکون‌ها.

- **Android (Chrome)**: سایت را باز کن → منوی سه‌نقطه → «افزودن به صفحهٔ اصلی» یا «Install app».
- **iPhone (Safari)**: دکمهٔ Share → «Add to Home Screen».
- آیکون‌ها با `python3 scripts/logo-icon.py` ساخته می‌شوند (Pillow؛ فونت Montserrat در صورت نبود خودکار دانلود می‌شود).
- Service worker فقط پوستهٔ اپ را کش می‌کند؛ درخواست‌های `/api` **هرگز** کش نمی‌شوند تا قیمت‌ها کهنه نشوند.
- **پولینگ تطبیقی (مصرف کم روی گوشی)**: تب پنهان کاملاً متوقف می‌شود، با بازار بسته فاصله‌ها چند برابر می‌شود و روی گوشی/Save-Data کندتر است؛ درخواست هم‌پوشان هم اجرا نمی‌شود. سیاست خالص در `src/utils/pollingPolicy.ts` و قلاب در `src/utils/adaptivePolling.ts`.
- پیش‌نمایش لینک (Open Graph): `public/og-image.png` ۱۲۰۰×۶۳۰ + متاهای OG/Twitter؛ آدرس مطلق با `PUBLIC_BASE_URL` (یا هدر درخواست) در پاسخ سرور تزریق می‌شود.
- **بررسی بعد از استقرار**: بعد از اینکه دامنهٔ واقعی روی HTTPS بالا آمد، `npm run check:pwa -- https://your-domain.com` را اجرا کن؛ شرط‌های نصب (manifest، آیکون‌های ۱۹۲/۵۱۲/maskable، service worker و start_url) را تک‌تک چک می‌کند. تست خودکار شرط‌ها هم در `tests/pwa.test.ts` است و با `npm test` اجرا می‌شود.
- برای **APK واقعی** سایت باید دامنه و HTTPS ثابت داشته باشد (PWA روی `localhost` یا دامنهٔ موقت قابل بسته‌بندی مطمئن نیست)؛ بعد از آن همین manifest را با PWABuilder یا Bubblewrap به APK تبدیل کن.
